# 自研验收基线

> 适用对象：单文件原型编辑器（`sample.prototype.html` / `editor-prototype/`）及其 `.prototype.html` 产物、prototype-html-builder skill、以及由原型驱动的界面实现。
> 基线来源：自研设计系统规格与内部实测值；**不引入任何第三方产品作为对照基准**。

## 一、验收分层

| 层级 | 验收对象 | 判定标准 |
| --- | --- | --- |
| L1 数据合法性 | `#__doc` / `#__ai_view` | `validate-doc.mjs` 通过；文档可解析、节点字段齐备、坐标符合画板局部坐标约定 |
| L2 编辑器功能 | 画布 / 图层 / 属性 / 组件 / 演示 / 持久化 | 功能矩阵逐项通过，控制台零报错；撤销重做、导入导出、刷新恢复闭环可用 |
| L3 视觉一致性 | 面板尺寸、间距节奏、配色、状态 | 与自研设计系统 Token 及内部实测规格一致；不要求与任何外部界面像素相等 |
| L4 AI 协作 | 四层 AI 入口 | `AI-NOTICE` + `meta[name=prototype-ai]` + `__doc.aiHint` + `PROTOTYPE-AI-GUIDE` + `#__ai_view` 头部齐备；`exportAI()` 输出与文件内容一致；保存 / 再生幂等 |
| L5 界面实现 | 由原型驱动的业务代码 | 布局层级与视觉整体一致，**且**遵循项目开发规范（标准组件、设计 Token、响应式、可访问性） |

## 二、L5 的硬约束（最高优先）

原型只提供**空间布局与 UI 元素整体效果**参考，不是逐像素代码规范：

- 必须：Vue3 / React 标准组件、组件库、设计系统 Token、路由与状态管理、响应式、可访问性。
- 必须：母版 / 实例 → 可复用组件 + props/slot，重复 UI 抽象为组件。
- 禁止：把图层清单逐节点翻译成绝对定位硬编码 DOM/CSS。
- 验收：布局与视觉整体一致且符合开发规范，**不要求像素 diff = 0**。

坐标（`x/y/w/h`）只用于理解相对层级与间距节奏，不作为绝对定位依据。
